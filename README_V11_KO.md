# V11 프로젝트 상세페이지 추가본

## WORK 이미지 효과
- 블러 완전 제거
- 확대 없음
- 마우스를 올리면 흰색 10% 투명 오버레이
- 사진 색과 선명도는 유지

## 프로젝트 상세페이지
경로:
- /work/calm-house/

구성:
- 왼쪽 400px 고정 정보 영역
- 상단 로고 유지
- 오른쪽 위 햄버거 메뉴 유지
- 블로그/인스타그램은 아이콘만 표시
- 프로젝트명, 주거형태, 면적, 위치, 연도 표시
- 오른쪽에는 사진만 세로 한 줄
- 가로사진은 폭 100%
- 세로사진은 가운데 정렬, 최대 폭 58%
- 원본 비율 유지
- 사진 사이 간격 70px

WORK 페이지 첫 번째 프로젝트를 누르면 상세페이지로 이동합니다.

Cloudflare:
- Build command: npm run build
- Build output directory: out

풍수 인테리어 메인 페이지

Cloudflare 업로드 방법
1. 이 ZIP 파일을 Cloudflare의 New deployment에 업로드합니다.
2. Deploy를 누릅니다.
3. Visit로 확인합니다.

메인 여백을 바꾸려면 styles.css 맨 위의 값을 수정하세요.

--hero-side: 좌우 여백
--hero-top: 사진 위 여백
--hero-ratio: 사진 가로/세로 비율


메뉴 버튼 변경
- 오른쪽 위 + 버튼을 동일 굵기의 가로 3줄 버튼으로 변경
- 클릭 시 시계 방향으로 90도 회전
- 다시 클릭하거나 메뉴의 × 버튼을 누르면 원래 방향으로 복귀


사이드 메뉴 변경
- 메뉴 클릭 시 메인 화면을 반투명 검정으로 어둡게 표시
- 사이드바 슬라이딩 애니메이션 제거
- 사이드바가 제자리에서 바로 나타남
- X 버튼의 선 색상과 굵기를 메뉴 버튼과 동일하게 적용
- 어두운 영역 클릭 또는 ESC 키로 메뉴 닫기

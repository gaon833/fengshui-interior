# V21 최종 기능 추가본

## 모바일 헤더
- 모바일에서 로고와 햄버거는 처음에 표시
- 50px 이상 아래로 스크롤하면 위로 부드럽게 사라짐
- 페이지 최상단으로 돌아오면 다시 표시
- 메뉴가 열린 동안에는 숨지 않음
- 애니메이션 0.35초

## 상세페이지 PREV / NEXT
- 마지막 사진 아래에 ← PREV / NEXT → 추가
- 현재 사이트 메뉴와 동일한 폰트, 두께, 자간 적용
- 프로젝트 등록 순서대로 이동
- 첫 프로젝트의 PREV는 마지막 프로젝트로 이동
- 마지막 프로젝트의 NEXT는 첫 프로젝트로 이동

## 상세페이지 전환
- PREV / NEXT 클릭 시 0.18초 페이드아웃
- 새 페이지 로드 시 0.25초 페이드인
- 슬라이드, 확대, 블러 효과 없음
- 모션 감소 설정 사용자는 전환 효과 자동 해제

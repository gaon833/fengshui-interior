# 풍수 인테리어 V3 Foundation Plus CMS

이 버전은 V3 공통 UI와 포트폴리오 구조에, 향후 실제 관리자 CMS를 연결하기 위한 운영 구조를 함께 반영한 새 뼈대입니다.

## 실제로 포함된 구조

### 사용자 홈페이지
- 공통 로고 컴포넌트
- 공통 NavigationList
- 고정 메뉴와 햄버거 드로어의 동일 메뉴 재사용
- 디자인 토큰 중앙 관리
- 프로젝트 목록
- 모던 프로젝트 상세 템플릿
- 갤러리
- PREV/NEXT 자동 계산
- 모바일 반응형 기본 틀

### 관리자 설계 틀
- 대시보드
- 프로젝트 목록
- 새 프로젝트 등록 화면
- 프로젝트 수정 화면
- 제목·상태·태그 편집
- 자동 저장 UX 예시
- 프로젝트 복제 버튼 자리
- 이미지 일괄 업로드·드래그 정렬·대표 이미지·썸네일 기능 자리
- 공개 / 비공개 / 작성 중 / 휴지통 상태
- 휴지통과 복원 화면
- 검색과 상태 필터 UI
- 프로젝트 순서 드래그 핸들
- SEO 제목·설명·OG 이미지
- 프로젝트 버전 기록·복원 구조
- 사이트 로고·SNS·문의·기본 SEO 설정
- 백업·다운로드·복원 화면
- 최고 관리자 / 편집자 / 읽기 전용 권한 구조
- 태그 데이터 구조

## 중요한 사실

현재 관리자 화면은 **CMS 설계와 화면 틀**입니다.
브라우저의 자동 저장 예시는 로컬 저장소에 임시 저장하지만, 실제 서버 DB·파일 업로드·로그인·권한 검사·백업 생성은 다음 단계에서 연결해야 합니다.

## 데이터의 단일 출처
- 사이트 설정: `content/site.json`
- 프로젝트: `content/projects.json`
- 관리자 사용자 예시: `content/admin-users.json`
- 백업 목록 예시: `content/backups/manifest.json`

## 실행
```bash
npm install
npm run dev
```

`v3-reset` 브랜치에 이 ZIP 내용 전체를 올리고 기존 `develop`은 보존하세요.

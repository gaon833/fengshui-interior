# V18 수정본

## 햄버거 메뉴
- 클릭하면 90도 회전
- 회전 시간 0.38초
- 메뉴 패널은 왼쪽에서 28px 이동하며 페이드 인
- 닫을 때도 동일하게 부드럽게 복귀

## 사이드바 반응형
- PC에서는 400px
- 화면이 작아질수록 clamp()로 220px까지 자연스럽게 축소
- 본문 시작점도 사이드바 폭과 함께 같이 이동
- 900px 이하에서는 고정 사이드바가 사라지고 햄버거 메뉴만 유지

## WORK
- 601px 이상은 2열 유지
- 두 열이 같은 비율로 함께 축소
- 이미지 사이 간격과 오른쪽 여백도 함께 축소
- 600px 이하 휴대폰에서만 1열 전환

## 상세페이지
- 왼쪽 정보 영역, 오른쪽 여백, 위 여백도 화면 폭에 맞춰 부드럽게 축소
- 900px 이하에서는 고정 정보 영역을 해제해 이미지가 가려지지 않도록 처리

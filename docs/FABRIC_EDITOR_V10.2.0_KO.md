# v10.2.0 Fabric Editor 개선

## 선 편집
- 새 가로선/세로선은 Fabric `Line` 객체로 생성
- 기본 굵기 1px
- 굵기 0 = 실제 선 없음
- 0.5px 단위 입력 지원
- 선 색상 즉시 변경
- 기존 v10.1에서 만들어진 Rect 기반 선도 굵기/색상 조절 호환

## 페이지 연결 표시
- 관리자 작업공간에서 페이지 사이의 카드 간격 제거
- 페이지가 하나의 긴 원페이지처럼 바로 이어져 표시
- 페이지 사이에는 1px 하늘색 구분선만 표시
- 페이지 라벨/그림자 제거
- 실제 공개 홈페이지에는 별도의 페이지 구분선이 추가되지 않음

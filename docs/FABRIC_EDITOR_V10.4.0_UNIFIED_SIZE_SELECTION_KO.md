# v10.4.0 공통 페이지 규격 + 선택 레이어 유지

## OUR STORY / PROCESS 동일 규격
- Desktop: 1420 × 900
- Mobile: 390 × 844
- OUR STORY와 PROCESS 모두 동일한 상수 사용
- 과거에 다른 크기로 저장된 페이지는 로딩 시 공통 크기로 자동 변환
- 기존 요소 left/top/scaleX/scaleY를 비율대로 함께 변환하여 디자인 유지
- 변환 데이터는 D1에 다시 저장
- '현재 화면 비율로 맞춤'은 제거하고 '공통 규격으로 맞춤'으로 변경

## 수정 중 레이어가 닫히는 문제
- 속성창에서 색상, 굵기, 위치, 크기, 회전, 텍스트, 필터 등을 수정할 때
  live canvas와 저장 JSON이 같으면 `loadFromJSON()`을 다시 실행하지 않음
- 따라서 현재 선택 레이어와 Inspector가 닫히지 않음
- Undo/Redo 등 실제 외부 JSON 재로드가 필요한 경우에도 기존 layerId를 기억했다가
  재로드 후 같은 레이어를 다시 선택하여 설정창을 유지
- 실제 사용자가 빈 캔버스를 클릭해 선택 해제하거나 삭제할 때만 닫힘

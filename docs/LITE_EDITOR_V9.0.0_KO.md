# 풍수 인테리어 Lite Editor v9.0.0

Polotno의 사용 흐름을 참고하되 Polotno 코드는 사용하지 않습니다.
핵심 조작 엔진은 MIT 라이선스 `react-moveable` + `react-selecto`입니다.

## 제공 기능
- 자유 X/Y 이동
- 8방향 크기 조절, 회전
- 요소/페이지 중앙 및 다른 요소 기준 Smart Guide/Snap
- 하늘색 Grid ON/OFF
- Shift 다중 선택 / 영역 다중 선택
- 텍스트, 이미지, 사각박스, 선
- 색상, 굵기, 투명도, 정렬 등 속성
- 레이어 앞으로/뒤로 및 레이어 목록
- 요소 복제/삭제
- Undo/Redo (최대 40단계)
- Desktop / Mobile 별도 좌표
- 페이지 추가 / 복제 / 삭제 / 좌우 순서 변경
- 하단 페이지 썸네일형 관리
- 기존 1920px / WebP 87% 이미지 최적화
- R2 저장, D1 문서 저장, 미사용 R2 이미지 정리

## 의도적으로 제외
Templates, stock photos, AI, draw, video, effects 등 홈페이지 운영에 필요 없는 기능.

# Fabric Full Editor v10.1.0

Fabric.js 7.4.0의 일반 편집 기능을 홈페이지 관리자에서 폭넓게 사용하도록 확장한 버전입니다.

## Fabric 기능
- 자유 이동 / 리사이즈 / 회전 / 다중 선택
- 텍스트와 상세 서식
- 이미지 및 밝기/대비/블러/흑백 필터
- 사각형, 원, 타원, 삼각형, 별, 가로/세로선
- SVG 가져오기
- Pencil / Spray / Circle 자유 드로잉
- 복사 / 붙여넣기 / 복제 / 삭제
- 그룹 / 그룹 해제
- 좌우/상하 반전, skew, 잠금
- 그라디언트 / 그림자
- 레이어 순서 및 레이어 목록
- 그리드 / 스마트 가이드 / 거리 표시 / Zoom
- Undo / Redo

## 홈페이지 전용 기능
- Desktop / Mobile 별도 디자인
- 페이지 추가 / 복제 / 삭제 / 순서 변경
- 페이지 썸네일
- D1 디자인 JSON 저장
- 기존 1920px / WebP 87% 이미지 최적화 및 R2 저장 유지

# Fabric Full Editor v10.5.2

- OUR STORY / PROCESS 페이지 하단에 직접 드래그 가능한 높이 조절 손잡이 추가
- 손잡이를 위/아래로 드래그해 콘텐츠 아래 여백과 페이지 높이를 직관적으로 조절
- 콘텐츠보다 작게 줄어들지 않도록 최소 높이 보호
- 드래그 종료 시에만 문서 상태를 저장해 편집 중 불필요한 재렌더링을 줄임
- 기존 숫자형 페이지 높이 / 하단 여백 입력과 자동 맞춤 기능 유지
- package.json 및 VERSION.txt 버전 10.5.2 적용

## 드래그 적용 유지 보정

페이지 높이 드래그 후 `page.height`가 변경될 때 Fabric Canvas 자체를 재생성하던 경로를 제거했습니다. 높이 변경은 기존 Canvas 인스턴스에 `setDimensions`로 직접 반영하고, 드래그 중/종료 직후의 표시 높이는 별도 상태와 ref로 유지합니다. 따라서 포인터를 놓는 순간 이전 높이로 되돌아가는 현상과 저장 직전 상태 경쟁을 방지합니다.

또한 공통 규격 정규화 검사에서 사용자 지정 높이를 오류로 보지 않도록 변경했습니다. Desktop은 900px, Mobile은 844px을 최소 높이로만 사용하며 그보다 큰 사용자 지정 높이는 그대로 보존합니다.

# OUR STORY / PROCESS 페이지형 자유 배치 편집기 v7.8.0

- Desktop 편집 화면: 16:9 실제 화면 비율
- Mobile 편집 화면: 9:16 세로 화면 비율, 768px 이하 자동 전환
- `+ 페이지 추가` 버튼으로 2페이지, 3페이지를 아래로 계속 추가
- 관리자에서 각 페이지를 세로로 스크롤하며 원페이지 사이트처럼 편집
- 각 요소는 해당 페이지 안에서 자유 드래그 / 크기 조절
- 요소별 페이지 이동 가능
- Desktop / Mobile 페이지 위치와 좌표는 각각 별도 저장
- 같은 텍스트/이미지 콘텐츠를 재사용
- 공개 홈페이지는 편집한 페이지 순서대로 세로로 이어져 표시
- 기존 이미지 최적화(WebP 87%, 긴 변 1920px), R2, D1 구조 유지

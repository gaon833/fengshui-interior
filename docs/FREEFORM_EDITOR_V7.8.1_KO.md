# 자유 배치 편집기 v7.8.1 - 실제 콘텐츠 영역 비율

Desktop 편집 캔버스는 16:9 고정이 아닙니다.

- 전체 브라우저 폭에서 왼쪽 고정 사이드바 400px 제외
- 오른쪽 디자인 여백 100px 추가 제외
- 남은 폭을 실제 OUR STORY / PROCESS 콘텐츠 폭으로 사용
- 높이는 현재 브라우저 viewport 높이(100vh)를 기준으로 사용
- 예: 1920×1080 화면이면 편집 영역은 약 1420×1080
- 공개 홈페이지도 site-content에서 오른쪽 100px을 제외하고 각 페이지 높이를 100vh로 표시
- Mobile(768px 이하)은 기존 9:16 미리보기/배치 유지
- 페이지 추가, 드래그, 크기 조절, D1/R2 및 이미지 최적화 기능 유지

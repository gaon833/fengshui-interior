# 풍수 인테리어 홈페이지 최종 통합본 V50

## 메뉴 시스템 통합
기본 페이지의 고정 메뉴와 햄버거 버튼을 눌렀을 때 나타나는 X 사이드바 메뉴가
모두 동일한 공통 클래스 `site-menu-nav`와 동일한 CSS 파일 `menu-system.css`를 사용합니다.

따라서 앞으로 아래 항목을 `menu-system.css`에서 한 번만 수정하면 두 메뉴에 동시에 반영됩니다.

- 글자 크기
- 글자 두께
- 글자 색상
- 자간
- 행간
- 메뉴 항목 간격
- 메뉴 시작 위치
- 구분선 길이, 색상, 간격
- BLOG / INSTAGRAM 스타일

- 프로젝트 필터: ALL 제외 카테고리는 왼쪽부터 오른쪽으로 배치
- 상세페이지 PREV / NEXT 스타일
- 로고 및 햄버거/X 아이콘 색상
- 모바일 스크롤 헤더 동작

- 기존 페이지 및 상세페이지 기능

# 풍수 인테리어 공통 메뉴 컴포넌트 최종본

이번 버전에서는 기본 페이지 메뉴와 햄버거(X) 메뉴가 단순히 같은 값을 복사한 것이 아니라,
실제로 동일한 메뉴 생성기와 동일한 CSS를 공유합니다.

## 공통 파일
- `shared-menu.js`
  - PROJECT / SERVICE / STUDIO / RESERVATION / BLOG / INSTAGRAM 메뉴를 한 번만 정의
  - 기본 메뉴와 X 메뉴에 동일한 HTML을 자동 생성
  - 현재 페이지에 따라 active 메뉴 자동 적용

- `shared-menu.css`
  - 폰트
  - 글자 크기
  - 글자 두께
  - 글자 색상
  - 자간
  - 행간
  - 메뉴 간격
  - 메뉴 위치
  - 구분선

앞으로 위 파일 한 곳만 수정하면 기본 메뉴와 X 메뉴가 함께 바뀝니다.
메뉴 이름이나 링크를 추가/삭제할 때도 `shared-menu.js` 한 곳만 수정하면 두 메뉴에 동시에 반영됩니다.

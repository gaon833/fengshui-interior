- ALL 화면은 기존 배치 그대로 유지
- 20 / 30 / 40 / 50 / 60 / C 필터는 첫 프로젝트가 왼쪽에서 시작
- 이후 왼쪽 → 오른쪽 순서로 채움
- 모바일은 한 줄이므로 왼쪽 열 기준으로 순서대로 표시

- PREV / NEXT 색상을 기존보다 조금 더 진한 회색으로 변경

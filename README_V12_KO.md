# V12 수정본

## 상세페이지 가로사진 기준
- 왼쪽 고정 영역: 800px
- 오른쪽 여백: 300px
- 상단 여백: 200px
- 가로사진: 남은 영역 폭 100%, 원본 비율 유지
- 세로사진: 같은 영역 안에서 중앙 정렬, 최대 폭 62%
- 사진 사이 간격: 70px

화면 폭이 좁아지면 반응형으로 자동 축소됩니다.

## 모든 WORK 프로젝트 연결
다음 6개 프로젝트에 각각 상세페이지가 생성되었습니다.
- CALM HOUSE
- LIGHT HALL
- LINE OFFICE
- QUIET ENTRY
- SOFT LIVING
- WARM MATERIAL

WORK 목록의 모든 프로젝트 카드를 클릭할 수 있습니다.

- 프로젝트 상세 관리 항목 추가
- 프로젝트명, 분류, 공간유형, 면적, 위치, 연도
- 대표사진
- 상세사진 여러 장

# V43 메뉴 스타일 실제 계산값 동기화

이번 버전은 숫자를 추정해 CSS로 맞추지 않습니다.

기본 페이지 메뉴의 브라우저 실제 계산값을 읽어,
X가 있는 햄버거 사이드바 메뉴에 그대로 복사합니다.

동기화 항목:
- 글꼴
- 글자 크기
- 글자 두께
- 글자 색상
- 자간과 단어 간격
- 행간과 메뉴 항목 높이
- 위아래 마진 및 패딩
- 메뉴 항목 간격
- 구분선 폭, 색상, 두께, 위치
- BLOG / INSTAGRAM 스타일
- 첫 PROJECT의 실제 화면 Y 좌표

메뉴를 열 때, 화면 크기가 바뀔 때, 클래스가 바뀔 때마다 자동 재동기화합니다.
기존 페이지 메뉴는 변경하지 않고 X가 있는 메뉴만 맞춥니다.
